Banco Grepe

Tela de um banco fictício feita com HTML, CSS e JavaScript puro, como projeto de estudo.

Funcionalidades

- Saldo com botão para ocultar e mostrar os valores
- Transferência para destinatários fictícios, com validação (destinatário obrigatório, valor maior que zero, saldo suficiente)
- Extrato atualizado a cada transferência, com entradas em verde e saídas em vermelho
- Layout responsivo para computador e celular

Tecnologias

HTML5, CSS3 (Grid, Flexbox e variáveis) e JavaScript.
